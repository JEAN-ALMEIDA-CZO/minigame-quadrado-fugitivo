Um jogo web hilário, provocativo e quase terapêutico.  
Tente clicar em um quadrado que **foge do seu mouse**, enquanto é desafiado por mensagens sarcásticas, risadas maldosas e lições de vida inesperadas.

---

## 🎮 Demonstração

Acesse agora e teste seus reflexos e sua paciência:  
👉 [**Ver Jogo em Ação**](https://jean-almeida-czo.github.io/minigame-quadrado-fugitivo)

---

## 🤡 Funcionalidades

- 🟥 **Quadrado em fuga**: cada clique faz ele ficar mais rápido e menor
- 🎯 **Pontuação dinâmica** com meta de 15 acertos
- 🔊 **Áudio de vitória** e **risadas aleatórias** após erros
- 😵 **Mensagens provocativas** para cada erro
- 🧘 **Modo Zen** desbloqueável para jogar com calma
- 🏆 **Modal de Vitória** com mensagem inspiradora e botão de copiar
- 📱 **Responsivo**: funciona bem no celular ou desktop

---

## 🧩 Estrutura do Projeto

```
docs/
├── index.html
├── assets/
│   ├── style.css
│   ├── script.js
│   ├── favicon/         # Ícones para várias plataformas
│   └── sons/            # Risadas e som de vitória
```

### Componentes principais:

- `#quadrado` — Elemento clicável que se move aleatoriamente
- `modalPermissaoAudio` — Solicita permissão para tocar som
- `modalZen` — Mensagem reflexiva e opção de entrar no Modo Zen
- `modalVitoria` — Exibe troféu e mensagem final

## 🚀 Como Usar

1. **Clone o repositório**:

   ```bash
   git clone https://github.com/JEAN-ALMEIDA-CZO/minigame-quadrado-fugitivo.git
   ```

2. **Abra o arquivo `index.html` no seu navegador favorito**.

3. Permita o som (opcional) e divirta-se tentando não perder a paciência.
